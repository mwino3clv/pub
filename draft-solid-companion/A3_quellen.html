Appendix C — Quellen / Weiterführendes

Dieser Anhang verzeichnet alle Quellen, auf die das Begleitheft zurückgreift, und gibt Hinweise für alle, die tiefer in die Themen einsteigen möchten. Die Quellen sind nach Themenbereich gegliedert; innerhalb jedes Bereichs stehen offizielle und primäre Quellen zuerst.

C.1 Quellenverzeichnis

C.1.1 Java — Offizielle Dokumentation

Oracle Java SE 21 Dokumentation — Oracle — https://docs.oracle.com/en/java/javase/21/

Die offizielle Referenz für Java 21. Enthält API-Dokumentation, Sprachspezifikation und Leitfäden. Primärquelle für alle Java-spezifischen Aussagen im Begleitheft.

dev.java — Aktuelle Java-Lernpfade — Oracle — https://dev.java/learn/

Der offizielle Nachfolger der Java Tutorials. Strukturierter Einstieg in moderne Java-Konzepte; regelmäßig aktualisiert.

The Java Tutorials (Archiv, JDK 8) — Oracle — https://docs.oracle.com/javase/tutorial/

Klassische Einführung in Java-Grundlagen, Collections, I/O und JDBC. Weiterhin als Referenz wertvoll, auch wenn der Nachfolger dev.java ist.

C.1.2 Java — Spezifische Themen

Java Interfaces — Oracle Java Tutorials — https://docs.oracle.com/javase/tutorial/java/IandI/createinterface.html

Erklärt, wie Interfaces definiert und implementiert werden. Grundlage für das Verständnis von ProductDao und dem DAO-Pattern.

Java Collections — Oracle Java Tutorials — https://docs.oracle.com/javase/tutorial/collections/index.html

Einführung in List, ArrayList und weitere Collection-Typen. Relevant für InMemoryProductDao und den Umgang mit List<Product>.

Java File I/O — Oracle Java Tutorials — https://docs.oracle.com/javase/tutorial/essential/io/index.html

Erläutert BufferedReader, BufferedWriter und FileReader/FileWriter. Grundlage für TextFileProductDao.

JDBC — Java Database Connectivity — Oracle Java Tutorials — https://docs.oracle.com/javase/tutorial/jdbc/index.html

Einführung in Connection, PreparedStatement und ResultSet. Grundlage für MariaDbProductDao.

C.1.3 Datenbank

MariaDB Connector/J — MariaDB Foundation — https://mariadb.com/kb/en/mariadb-connector-j/

Offizielle Dokumentation des JDBC-Treibers für MariaDB. Enthält Installationshinweise, Verbindungs-URLs und Konfigurationsoptionen.

C.1.4 SOLID-Prinzipien

S.O.L.I.D: The First Five Principles of Object-Oriented Design — DigitalOcean — https://www.digitalocean.com/community/conceptual-articles/s-o-l-i-d-the-first-five-principles-of-object-oriented-design

Zugängliche Einführung in alle fünf SOLID-Prinzipien mit Java-Beispielen. Sekundärquelle; gut geeignet als ergänzende Lektüre.

C.1.5 DAO-Pattern

The DAO Pattern in Java — Baeldung — https://www.baeldung.com/java-dao-pattern

Praxisnahe Erklärung des DAO-Patterns mit vollständigen Java-Beispielen. Zeigt Interface, Implementierung und Verwendung anhand eines vollständigen Beispiels.

C.1.6 Bücher

Martin, Robert C. „Clean Code: A Handbook of Agile Software Craftsmanship”. Prentice Hall, 2008.

Standardwerk zu Codequalität und gutem Softwareentwurf. Behandelt Benennung, Funktionen, Klassen und SOLID-Prinzipien ausführlich. Empfehlung für alle, die tiefer in den Bereich Softwaredesign einsteigen möchten.

C.2 Weiterführende Links

Wer die Themen des Begleithefts vertiefen möchte, findet hier einen Einstieg.

C.2.1 Java vertiefen

dev.java — Java-Lernpfade — https://dev.java/learn/

Strukturierter Einstieg in moderne Java-Konzepte. Behandelt unter anderem Lambdas, Streams, Records und moderne API-Nutzung.

Baeldung — Java-Tutorials — https://www.baeldung.com/

Umfangreiche Sammlung von Java-Tutorials zu Standardbibliothek, Frameworks und Entwurfsmustern. Gut geeignet als Nachschlagewerk für konkrete Java-Fragen.

C.2.2 Entwurfsmuster

Refactoring.Guru — Design Patterns — https://refactoring.guru/design-patterns

Illustrierte Einführung in häufige Entwurfsmuster, darunter DAO und Dependency Injection. Verfügbar auf Englisch und in weiteren Sprachen.

C.2.3 Datenbanken

MariaDB-Dokumentation — https://mariadb.com/kb/en/

Offizielle Dokumentation zu Installation, SQL-Syntax und Konfiguration. Einstiegspunkt für alle, die MariaDB produktiv einsetzen möchten.

SQL-Tutorial (W3Schools) — https://www.w3schools.com/sql/

Interaktive Einführung in SQL-Grundbefehle (SELECT, INSERT, UPDATE, DELETE). Gut geeignet für einen schnellen Einstieg ohne Vorkenntnisse.

C.2.4 SOLID und Softwaredesign

Martin, Robert C. „Principles of OOD” — http://butunclebob.com/ArticleS.UncleBob.PrinciplesOfOod

Originalartikel von Robert C. Martin, in dem die SOLID-Prinzipien erstmals zusammengefasst sind. Englischsprachig; für alle, die die Primärquelle lesen möchten.
